# Text Replacer

[English](README.md) · **Русский**

[![CI](https://github.com/Pavel-us/TextReplacer/actions/workflows/ci.yml/badge.svg)](https://github.com/Pavel-us/TextReplacer/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

Быстрая кроссплатформенная программа для **пакетного поиска и замены текста в файлах**. Windows, Linux и macOS.
Современная альтернатива классическим утилитам вроде «Text Replacer»: движок написан на Rust
(файлы обрабатываются параллельно), интерфейс построен на [Tauri](https://tauri.app).

## Возможности

- Рекурсивный обход папок, маски имён (`*.html;*.txt`), папка `.git` пропускается
- Многострочный поиск и замена; точное совпадение (пробелы по краям сохраняются)
- Режим «пробелы и переводы строк не важны», поиск с учётом и без учёта регистра
- Регулярные выражения с группами (`$1`, `$2` в замене)
- **Пакетная замена**: список правил, выполняемых по порядку, или файл правил
- **Предпросмотр** (пробный прогон), `.bak`-копии, атомарная запись, лимит размера файла
- Автоопределение кодировок (UTF-8, UTF-16, cp1251), сохранение стиля переводов строк (LF / CRLF)
- Перетаскивание папки или файла в окно
- Тёмная / светлая / системная тема, запоминание настроек
- `.rtf` правится на месте с сохранением форматирования
- Встроенная справка (кнопка **?**) с быстрым стартом и десятью готовыми рецептами регулярных выражений
- Автоматическая проверка обновлений с показом того, что изменилось
- **Языки интерфейса**: английский и русский, новые добавляются без пересборки

## Поддерживаемые форматы

| Формат | Расширения | Что обрабатывается |
|---|---|---|
| Обычный текст | любые (по маске) | UTF-8 / UTF-16 / cp1251 |
| Word | docx, docm, dotx, dotm | текст, таблицы, колонтитулы, сноски |
| Excel | xlsx, xlsm, xltx, xltm | строковые значения ячеек (общие и inline-строки) |
| PowerPoint | pptx, pptm, potx, potm, ppsx, ppsm | текст слайдов и заметок |
| LibreOffice / OpenOffice | odt, ods, odp, odg, ott, ots, otp, otg | `content.xml`, `styles.xml` (в т. ч. колонтитулы) |
| Старый Office | doc, xls, ppt | не поддерживается — сначала сохраните как docx / xlsx / pptx (такие файлы пропускаются с подсказкой) |
| RTF | rtf | правка на месте с сохранением форматирования (кириллица и другие кодовые страницы) |
| PDF *(экспериментально)* | pdf | только латиница в простых шрифтах — см. ниже |

В офисных форматах форматирование сохраняется, даже если фраза разбита на куски с разным стилем.
Поиск может пересекать абзацы: укажите в «Найти» несколько строк с переносами. Ячейки таблиц остаются барьером — совпадение не выходит за границу ячейки.
Не затрагиваются: формулы, имена листов, комментарии, диаграммы, свойства документа.

### Старые форматы (.doc, .xls, .ppt)

Старые бинарные файлы Word 97 / Excel 97 / PowerPoint 97 **пропускаются** (в таблице результатов это написано). Их нельзя безопасно править «на месте»,
а автоматическая конвертация, как выяснилось, теряет шрифты и таблицы и даже искажает текст. Откройте такой файл в Word или LibreOffice,
сохраните как `.docx` / `.xlsx` / `.pptx` и обработайте новый файл.

### RTF

`.rtf` правится **на месте** встроенным разборщиком: заменяется только текст, все команды форматирования остаются.
Текст, разбитый сменой жирного, курсива или цвета, тоже находится. Поиск может пересекать абзацы (в `«Найти»` укажите переносы строк), но не ячейки таблиц.
Поддерживаются кодовые страницы (`\ansicpg`, кодировки шрифтов: 1250–1258, 874, 866, KOI8) и экранирование `\uN`; новый текст записывается как `\uN`.

### Ограничения PDF

PDF хранит не текст, а команды рисования глифов шрифта, поэтому правка принципиально ограничена:

- Находится только латиница в простых шрифтах. Кириллица и текст в шрифтах Identity-H (большинство современных PDF) — нет.
- Пробелы между словами часто задаются сдвигом, а не символом — ищите отдельные слова, а не фразы.
- Во встроенном шрифте обычно только уже использованные глифы: новые символы могут отобразиться пустыми. Вёрстка не перестраивается.
- Зашифрованные и повреждённые PDF пропускаются.

Для серьёзной правки PDF конвертируйте в docx, правьте и экспортируйте обратно. PDF-модуль можно отключить при сборке:
`cargo build --no-default-features`.

## Справка и рецепты

Кнопка **?** в правом верхнем углу открывает справку: быстрый старт, список поддерживаемых форматов и десять готовых рецептов
регулярных выражений (сжать пробелы, поменять формат даты, убрать HTML-теги, сменить домен …). Кнопка **Применить** заполняет поля
и включает регулярные выражения — после этого подстройте рецепт под свой случай.

## Обновления

При запуске программа ищет более новую версию в GitHub Releases (это можно отключить в Справка → О программе) и, если она есть,
показывает окно с описанием **что нового**. Решаете вы: обновить сейчас, позже или пропустить эту версию.
Windows, macOS и AppImage обновляются сами (загрузка проверяется подписью); установка из `.deb` / `.rpm` сама обновиться не может,
поэтому окно предлагает страницу загрузки. Достаточно поставить новый `.deb` поверх старого.

В Linux пакет `.deb` помещает программу в раздел **«Офис»** меню приложений.

## Как пользоваться

1. Выберите папку (или перетащите её в окно) и при необходимости маску имён.
2. Введите искомый текст и замену. Кнопкой **＋ Добавить в список** соберите пакет правил
   или загрузите правила из файла.
3. Нажмите **Предпросмотр**, чтобы увидеть, что изменится, затем **Выполнить замену**.
4. Двойной щелчок по строке результата открывает папку с файлом.

**Формат файла правил** — одно правило в строке, `найти<TAB>заменить`; допустимы `\n` и `\t`; строки на `#` — комментарии:

```text
# старый бренд -> новый бренд
Acme Corp	Globex Inc
http://old.example.com	https://new.example.com
```

**Регулярные выражения** используют синтаксис Rust [`regex`](https://docs.rs/regex): внутри шаблона нет look-around и обратных ссылок,
зато нет и катастрофического backtracking. В замене — `$1`, `$2` или `${имя}`; `$$` — символ доллара.
В обычном режиме (без regex) `$` всегда обычный символ.

## Языки

Язык интерфейса выбирается в боковой панели. При первом запуске берётся язык системы.

**Добавить язык без пересборки** (для пользователей):

1. Нажмите кнопку 📂 рядом с выбором языка — откроется папка переводов, в ней создастся `_template.json`:
   - Linux: `~/.config/dev.textreplacer.app/locales/`
   - macOS: `~/Library/Application Support/dev.textreplacer.app/locales/`
   - Windows: `%APPDATA%\dev.textreplacer.app\locales\`
2. Скопируйте `_template.json`, например в `de.json`, укажите `_meta.code` (`de`) и `_meta.name` (`Deutsch`), переведите значения.
   Плейсхолдеры вроде `{0}` не меняйте. Файлы, имена которых начинаются с `_`, игнорируются.
3. Вернитесь в приложение — новый язык появится в списке. Недостающие ключи берутся из английского.

**Добавить язык в проект** (для разработчиков): см. [CONTRIBUTING.md](CONTRIBUTING.md#русский).
Файл проверяется командой `npm run check:locales`.

## Сборка из исходников

Требования: [Rust](https://rustup.rs), Node.js 18+ и [зависимости Tauri](https://v2.tauri.app/start/prerequisites/)
(Windows: MSVC Build Tools; Debian/Ubuntu: `libwebkit2gtk-4.1-dev build-essential curl wget file libxdo-dev libssl-dev libayatana-appindicator3-dev librsvg2-dev`).

```bash
npm install
npm run dev        # окно для разработки
npm run build      # установщики и бинарник в src-tauri/target/release/
npm run test       # проверка переводов + тесты движка
```

Кросс-компиляции нет: собирайте на каждой целевой ОС или доверьте это GitHub Actions
(**Actions → Build → Run workflow**, либо отправьте тег `v*`, чтобы получить Release с архивами).

## Релизы и автоматические обновления

*Для разработчика.* Обновления подписываются, поэтому один раз нужна пара ключей:

1. `npx tauri signer generate -w ~/.tauri/textreplacer.key` (пароль можно оставить пустым).
2. `node scripts/set-updater-key.mjs ~/.tauri/textreplacer.key.pub`, затем закоммитьте `src-tauri/tauri.conf.json`.
3. На GitHub: *Settings → Secrets and variables → Actions → New repository secret*:
   `TAURI_SIGNING_PRIVATE_KEY` = всё содержимое файла `~/.tauri/textreplacer.key`
   (и `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`, если задавали пароль).
4. **Сохраните резервную копию приватного ключа.** Если он потеряется, установленные копии больше нельзя будет обновить.

Чтобы выпустить версию: опишите изменения в `CHANGELOG.md` под заголовком `## [x.y.z]` с маркерами `<!-- lang:en -->` / `<!-- lang:ru -->`
(этот текст станет описанием релиза и разделом «что нового» в окне обновления), поднимите версию в `package.json`,
`src-tauri/Cargo.toml` и `src-tauri/tauri.conf.json`, затем отправьте тег: `git tag vX.Y.Z && git push origin vX.Y.Z`.
Workflow соберёт все платформы, подпишет файлы, создаст релиз и загрузит `latest.json`.
Локальная сборка без подписи: `npm run build:local`.
